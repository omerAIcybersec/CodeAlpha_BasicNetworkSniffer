Network Sniffer

A Python-based network sniffer that captures and analyzes network packets. This project is designed for learning purposes to understand how network traffic can be monitored and how packet information can be displayed.

Features

Captures network packets.
Displays basic packet information.
Helps analyze network traffic.
Provides practical experience with Python networking.
Useful for learning basic network security concepts.

Requirements

Python 3.x
Scapy

Installation

Clone the repository:
bash
git clone https://github.com/jiyarana696-cell/CodeAlpha_BasicNetworkSniffer
cd CodeAlpha_BasicNetworkSniffer

Install the required Python library:

bash
pip install scapy

Usage

Run the Python script:
bash
python network_sniffer.py

Depending on your operating system, administrator/root privileges may be required to capture packets.
